## 범위 정책

- Chapter 1의 도구 설치(p.4–6)는 `00-technical-requirements.md`에 정리한다. p.6은 GitHub 준비와 Application Context가 이어져 두 노트의 출처 범위가 겹친다.
- 한 파일이 연속된 여러 하위 목차 항목을 포함할 때 페이지 범위를 합쳐 표시한다. 예: Node.js·React 연동 노트는 번들링과 React 컴포넌트 구현(p.48–58)을 한 흐름으로 묶는다.
- Chapter 16은 학습 본문이 아니라 출판사 혜택 안내이므로 제외한다. Preface, Other Books, Index도 개념 노트 범위에서 제외한다.
