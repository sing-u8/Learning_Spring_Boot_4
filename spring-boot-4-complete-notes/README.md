# Learning Spring Boot 4 완전 학습 노트

이 저장소는 *Learning Spring Boot 4* (4th ed., 2026)의 본문을 책 순서대로 재구성한 개인 학습용 노트다. 대화와 본문은 한국어, 파일명은 검색과 Obsidian 링크를 위해 영어 kebab-case를 사용한다.

## 범위

- Part 1–7, Chapter 1–15의 학습 본문
- Spring Boot 4.1, Java 25라는 책의 버전 맥락
- 89개 주제 노트, 15개 Chapter 개념 지도, Chapter별 용어집
- 원문 대량 전재가 아닌 설명 재구성; 페이지 범위는 [[BOOK-COVERAGE]]에서 추적

## 학습 환경

- Java 25와 현대적인 IDE가 책의 실습 기준이다.
- 예제 코드는 책의 다운로드 번들과 함께 실행하면 좋다.
- Spring Boot 공식 문서는 버전 차이 확인용 보조 자료이며, 이 저장소의 설명 순서와 예제 맥락은 책을 우선한다.

## deep-tutor 사용법

1. Chapter의 `_map.md`로 큰 흐름을 먼저 본다.
2. 주제 노트는 구분자 위의 정리물만 읽는다.
3. 읽은 뒤 구분자 아래 `내 설명 시도`에 자신의 말로 설명한다.
4. 막힌 연결은 `_global/gaps.md`에 기록한다.
