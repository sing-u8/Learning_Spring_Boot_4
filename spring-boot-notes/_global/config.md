# Config

## 정리 모드
mode: batch        # on-demand | batch

- `on-demand` — 이번에 공부할 한 단위만 정리. 앞 세션의 막힌 지점을 반영할 수 있다
- `batch` — 챕터/책 통째로 정리. 시작 전 범위 견적을 제시하고 확인을 받는다
