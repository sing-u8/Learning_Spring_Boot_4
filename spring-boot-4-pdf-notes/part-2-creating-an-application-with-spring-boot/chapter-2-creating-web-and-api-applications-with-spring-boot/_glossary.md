# Chapter 2 용어집

- **Spring Initializr**: 선택한 버전·빌드·스타터로 프로젝트 골격을 만드는 서비스. → [[01-using-start-spring-io-to-build-apps]]
- **Spring MVC**: 서블릿 기반 Model-View-Controller 웹 프레임워크. → [[02-creating-a-spring-mvc-web-controller]]
- **logical view name**: 실제 템플릿 위치를 추상화한 컨트롤러 반환값. → [[02-creating-a-spring-mvc-web-controller]]
- **Mustache**: 이름 있는 모델 데이터를 HTML에 끼워 넣는 logic-less 템플릿 엔진. → [[04-leveraging-templates-to-create-content]]
- **Jackson**: Java 객체와 JSON을 직렬화·역직렬화하는 라이브러리. → [[05-creating-json-based-apis]]
- **frontend-maven-plugin**: Maven 생명주기에서 프로젝트 로컬 Node 작업을 실행하는 플러그인. → [[06-integrating-nodejs-with-a-spring-boot-web-app]]
- **bundle**: 브라우저 배포를 위해 모듈·의존성을 결합한 정적 산출물. → [[07-bundling-javascript-and-building-a-react-app]]
- **API versioning**: 호환되지 않는 여러 HTTP 계약을 명시적으로 식별하는 방식. → [[08-versioning-apis-with-spring-boot-4]]
- **HTTP Service Interface**: 애노테이션이 붙은 Java 인터페이스로 원격 호출을 선언하는 모델. → [[09-calling-versioned-apis-with-http-service-clients]]
- **JSpecify**: Java nullness 애노테이션의 공통 의미를 정의하는 명세. → [[10-writing-null-safe-applications-with-jspecify]]
