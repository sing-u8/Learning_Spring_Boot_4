- **Spring Data**: 저장소별 모듈과 repository 추상화를 제공하는 프로젝트군. → [[01-adding-spring-data-to-an-existing-application]]
- **JPA**: Java 객체 영속성의 표준 명세. → [[01-adding-spring-data-to-an-existing-application]]

- **Pageable**: 페이지 번호·크기·정렬을 담는 요청. → [[04-using-custom-finders-sorting-and-limits]]
