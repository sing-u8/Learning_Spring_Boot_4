# Chapter 11 용어집

| 용어 | 뜻 |
|---|---|
| Virtual thread | JVM이 scheduling하는 경량 Java thread |
| Platform thread | OS thread에 대응하는 전통 Java thread |
| Carrier thread | virtual thread를 실제로 실행하는 platform thread |
| Project Loom | Java concurrency 모델 개선 프로젝트 |
| TaskExecutor | background task 실행을 추상화한 Spring interface |
| RestClient | Spring의 동기식 fluent HTTP client |
| HTTP interface proxy | annotation interface로 remote API client를 생성하는 방식 |
| CompletableFuture | 비동기 결과와 후속 흐름을 표현하는 Java API |
| Structured concurrency | 관련 child task의 lifecycle을 하나의 scope로 관리하는 모델 |
