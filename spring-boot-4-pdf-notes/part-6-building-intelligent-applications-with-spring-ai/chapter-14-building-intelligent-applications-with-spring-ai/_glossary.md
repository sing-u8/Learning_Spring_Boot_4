# Chapter 14 용어집

| 용어 | 뜻 |
|---|---|
| ChatClient | Spring AI의 fluent high-level model client |
| ChatModel | provider-neutral chat model abstraction |
| Advisor | model request·response 주변에 memory·RAG·logging 등을 합성하는 interceptor형 구성 요소 |
| Tool calling | model이 application function 호출을 요청하는 방식 |
| Embedding | semantic meaning을 표현한 numeric vector |
| Vector store | vector similarity search storage |
| RAG | retrieved context로 generation을 grounding하는 architecture |
| Chat memory | conversation별 이전 message를 보존·주입하는 mechanism |
| MCP | remote AI capability discovery·invocation protocol |
| LLM-as-a-Judge | model이 다른 model output의 semantic quality를 평가하는 방식 |
| Prompt injection | untrusted instruction이 model behavior를 탈취하려는 공격 |
