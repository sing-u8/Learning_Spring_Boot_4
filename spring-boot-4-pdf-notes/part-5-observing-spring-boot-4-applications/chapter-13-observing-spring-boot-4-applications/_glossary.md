# Chapter 13 용어집

| 용어 | 뜻 |
|---|---|
| Telemetry | system이 외부로 내보내는 관측 데이터 |
| Observation | 한 unit of work에서 여러 signal을 만드는 Micrometer abstraction |
| OTLP | OpenTelemetry Protocol |
| Collector | telemetry 수신·처리·routing service |
| Loki | log backend |
| Prometheus | time-series metric storage/query engine |
| Tempo | distributed trace backend |
| Grafana | 여러 telemetry backend를 query·시각화하는 UI |
| Trace ID | 하나의 end-to-end trace를 식별하는 값 |
| Span ID | trace 안의 개별 작업을 식별하는 값 |
| Cardinality | label·attribute 값 조합의 다양성 |
