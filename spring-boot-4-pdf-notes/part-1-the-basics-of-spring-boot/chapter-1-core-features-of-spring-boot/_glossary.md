# Chapter 1 용어집

- **application context**: Spring Bean을 생성하고 연결하며 생명주기를 관리하는 컨테이너. → [[01-autoconfiguring-spring-beans]]
- **Spring Bean**: application context가 생성·관리하는 객체. 일반 JavaBean 규약과 같은 말이 아니다. → [[01-autoconfiguring-spring-beans]]
- **dependency injection**: 객체가 협력자를 직접 생성하지 않고 컨테이너로부터 받는 설계 방식. → [[01-autoconfiguring-spring-beans]]
- **autoconfiguration**: 클래스패스·기존 Bean·설정값을 조건으로 기반 Bean을 자동 제공하는 기능. → [[01-autoconfiguring-spring-beans]]
- **back-off**: 사용자 정의 Bean이 있을 때 기본 자동 구성이 물러나는 정책. → [[01-autoconfiguring-spring-beans]]
- **starter**: 기능 영역별 권장 의존성 묶음. → [[02-adding-portfolio-components-using-spring-boot-starters]]
- **configuration properties**: 외부 설정을 키 또는 타입 있는 객체로 제공하는 Spring Boot 모델. → [[03-customizing-the-setup-with-configuration-properties]]
- **profile**: 환경별 설정·Bean 조합에 붙인 이름. → [[03-customizing-the-setup-with-configuration-properties]]
- **BOM**: 호환 의존성 버전을 한곳에서 관리하는 Bill of Materials. → [[04-managing-application-dependencies]]
- **CVE**: 공개 식별자를 가진 알려진 보안 취약점. → [[04-managing-application-dependencies]]
