# Chapter 7 용어집

- **uber JAR**: application, nested dependencies, embedded server를 담은 실행 archive. → [[01-creating-an-uber-jar]]

- **image layer**: container filesystem의 content-addressed 변경 단위. → [[02-building-a-docker-container]]
- **container registry**: image를 저장·배포하는 service. → [[03-publishing-an-image-to-docker-hub]]
- **horizontal scaling**: 동일 application instance 수를 늘리는 확장. → [[04-tuning-and-scaling-in-production]]
- **Docker Compose**: multi-container 환경 선언·실행 도구. → [[04-tuning-and-scaling-in-production]]
- **database migration**: schema/data 변화를 versioned·repeatable하게 적용하는 process. → [[04-tuning-and-scaling-in-production]]
