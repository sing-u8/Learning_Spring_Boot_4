# Chapter 6 용어집

- **ConfigurationProperties**: prefix 아래 설정을 타입에 binding하는 Boot 모델. → [[01-creating-custom-properties]]
- **profile**: 환경별 설정·Bean 집합의 이름. → [[02-creating-profile-based-property-files]]
- **YAML**: indentation으로 map/list를 표현하는 config 형식. → [[03-switching-to-yaml-and-metadata]]
- **configuration metadata**: IDE가 key/type/설명을 제공하도록 생성한 정보. → [[03-switching-to-yaml-and-metadata]]
- **relaxed binding**: dot, hyphen, underscore, case 변형을 같은 property로 해석하는 규칙. → [[04-setting-properties-with-environment-variables]]
- **property source precedence**: 중복 key의 최종 값을 정하는 우선순위. → [[05-ordering-property-overrides]]
- **Twelve-Factor config**: 환경별 값을 code와 분리하는 원칙. → [[05-ordering-property-overrides]]
